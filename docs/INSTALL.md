# Install

## Install the app on your device
1. Download the APK to your phone or tablet (see Download on the [README](../README.md)).
2. Open the APK file.
3. When Android asks, allow installs from the app you opened it with (for example your browser or file manager).
4. Tap Install, then open MibExplorer.

A newer build installs over an older one only if both were signed with the same key.

## Connect to a unit
Follow "First connection" in the [User guide](USER-GUIDE.md).

## Only if your unit has no SSH
For setup instructions, see https://github.com/nadeem2626/mhi2-sshd
